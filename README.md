# PixelPulse Studio

Production-ready static site for PixelPulse Studio. This repository contains the site source (index.html) intended for GitHub Pages.

To deploy:

1. The site is already pushed to this repository's `main` branch.
2. GitHub Pages can serve from the repository root on the `main` branch. In your repository settings -> Pages, ensure Source is set to "Main" and folder is "/ (root)".

Default Pages URL (once enabled):
https://noha272.github.io/pixelpulse-studio/

If you want a custom domain, add a `CNAME` file with your domain in the repository root and update DNS to point to GitHub Pages per the GitHub documentation.
